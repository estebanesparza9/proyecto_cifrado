# proyecto_cifrado
Aplicación web interactiva para cifrar/descifrar textos usando: - Cifrado César (shift adjustable) - Cifrado Atbash (espejo) - Charset definido por el usuario - Interfaz cyberpunk con feedback visual  -Construido con Angular + Bootstrap

## Lógica del proyecto

Todo el cerebro de la aplicación está en:
src/app/app.ts
Ahí encontrará la implementación completa de los algoritmos de cifrado, la gestión del estado y la lógica de interacción.
